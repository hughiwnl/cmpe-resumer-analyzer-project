# Sample Data

Use these files to try out ResumeMatch without needing your own resume.

- `sample_job_description.txt` — paste this into the job description text area.
- `sample_resume_strong.pdf` / `.docx` — a resume with strong overlap with the sample job description (expect a high score).
- `sample_resume_weak.pdf` / `.docx` — a resume with little overlap with the sample job description (expect a low score).
- `*.txt` versions of each resume are included as plain-text source for reference; upload the `.pdf` or `.docx` versions to the app (those are the supported formats).

These are entirely fictional and contain no real personal information.
